Original and processed data supporting the study of nickel nitridation and morphological evolution in porous Ni-GDC electrodes. The dataset contains microscopy images and phase-segmentation results, GI-XRD, XPS, ToF-SIMS and gas chromatography measurements, and numerical data for nitridation-boundary analysis and metal-supported SOFC modelling.
