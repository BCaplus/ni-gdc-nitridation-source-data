# Source data for Ni-GDC electrode sample nitriding

Contributors: Kai Xu and Xiaoqing Zhang.

Original and processed data supporting the study of nickel nitridation and morphological evolution in porous Ni-GDC electrodes. The dataset contains microscopy images and phase-segmentation results, GI-XRD, XPS, ToF-SIMS and gas chromatography measurements, and numerical data for nitridation-boundary analysis and metal-supported SOFC modelling.

Download [Source_Data.zip](https://github.com/BCaplus/ni-gdc-nitridation-source-data/releases/download/v1.0.0/Source_Data.zip) from the [v1.0.0 release](https://github.com/BCaplus/ni-gdc-nitridation-source-data/releases/tag/v1.0.0).

The archive contains Microscopy, GI-XRD, XPS, ToF-SIMS, GC, Local_boundary and Cell_model folders. Its README describes each folder and the file formats.
